Аналитический слой интернет-магазина.

Сырые данные из базы магазина сервис loader копирует в Greenplum, в схему raw.
Из них dbt строит три слоя:
- staging - очищенные копии сырых таблиц, по одной модели на таблицу;
- intermediate - промежуточные расчёты: соединения таблиц, суммы по заказам, дерево категорий;
- marts - готовые витрины для анализа.

Витрины: fct_orders (заказы), fct_order_items (товары в заказах), dim_customers (клиенты), dim_products (товары), dim_dates (календарь).
